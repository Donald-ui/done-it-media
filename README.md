# DONE IT — médias publics

Visuels et vidéos finaux des publications DONE IT, hébergés ici pour obtenir des liens publics (Metricool, Meta).

Règles :
- uniquement des fichiers finaux à publier (PNG, JPG, MP4), jamais de fichiers de travail, de données clients ni de secrets ;
- chaque fichier est déposé la veille de sa publication, et peut être retiré une fois publié ;
- rangement : `AAAA-MM/JJ-sujet.ext`.
